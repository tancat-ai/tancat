TanCat launch checklist

Owner: Cat Tan Operations Ltd (company number 17576111). Free + Pro only. Pro is $499 per deployment, one-off, with a $125 a year renewal for optional later updates that nobody is charged automatically. The store account is in review and not approved: nothing here names it, and no buyer page does either.

The design, in four lines. The store issues a licence key with the order. The buyer activates it once, through our relay. It is checked again only when they install a new version. In between, the product reads the key stored on the machine and works offline - so a key the store disables is noticed at the next update, not before.

What must be true before the first sale

  • The store is approved, and its name is set in src/licensing/merchant.py (one constant). Until then every page says "our merchant of record".
  • The product sells as one one-off at $499 in USD - not a subscription, and with no automatic renewal item.
  • The product has a licence-key feature: one key per purchase, activation limit 1, no expiry.
  • The relay is deployed (services/licence-relay), its merchant API key is a secret, and POST /activate answers for a real test key.
  • The buyer learns where the key is: confirmation page, receipt and customer portal.
  • Every price on every surface matches src/licensing/pricing.py (parity check below).
  • A test purchase has been made, activated, checked, released and refunded.
  • The landing page's checkoutUrl is set and Buy Pro opens the live checkout.
  • Terms, privacy and DPA are live and name no provider.

The checklist

1. Store and product

  • Store created in the right country and currency: USD. The price is set in US dollars; any other currency makes the page wrong.
  • Store activated: identity, business/tax details, payout account.
  • Product TanCat Pro Deployment, one-off, $499, no renewal item.
  • Licence-key feature on: activation limit 1, no expiry. The feature's id is what the relay returns as activation_limit.
  • Feature list pasted: unlimited runs and evidence exports, POM mode, CI/CD Action, email support and setup help (two working days), perpetual licence with 12 months of updates, one deployment. Add nothing that is not in src/licensing/tiers.py.

2. Relay

  • cd services/licence-relay && npx wrangler login
  • npx wrangler secret put API_KEY - the merchant API key, pasted, never committed.
  • API_BASE in wrangler.toml set to the store's API base for this environment (test or live). The shipped placeholder fails closed on purpose.
  • npx wrangler deploy, then the three calls in the relay README answer: activate, validate, deactivate.
  • The product points at it: AITEST_LICENCE_RELAY_URL set, or the custom route matches the default in src/licensing/activation.py.

3. Price parity

  • pytest tests/test_landing_price.py -q green: the pages carry $0, $499 and $125, and no pound sign.
  • python scripts/maintenance/make_landing_assets.py then landing_assets_guard.py --check - the price is inside the preview images.
  • Read the card, the install page, the terms row and docs/user/reference/licensing.md: all say $499 and $125 a year.
  • Read the order PDF (landing/tancat-pro-install-and-licence.pdf): it is the licence document and carries no price at all - check that it neither states nor implies one, and that it still names tancat licence activate.

4. The buyer's path, end to end

  • Set checkoutUrl in landing/index.html; Buy Pro opens the checkout in a new tab. An empty value falls back to the contact section, so a half-finished launch cannot take money.
  • Test purchase: the order completes and the key appears on the confirmation page and in the receipt.
  • Activate: tancat licence activate <KEY> succeeds, and tancat licence status reports the instance, the activation date and the window end.
  • The window is 12 months from the key's creation date, not from the install date. Check the date in the status output.
  • Offline: after activation, disconnect the network and start the product. It runs on the paid tier, because it reads the stored licence.
  • Update: tancat update checks the key once. With the network down it proceeds and says the check could not be made.
  • Release: tancat licence release frees the instance; re-activating the same key then works.
  • Refund the test order and delete it.

5. Go live

  • Test mode off; buy one for real, activate, then refund.
  • tancat.dev/#pricing shows $499 and $125 a year.
  • The install page names tancat licence activate, tancat licence status and AITEST_LICENCE_FILE, and no dead route.
  • Terms, privacy and DPA say "our merchant of record" and name no provider.
  • python scripts/audit_egress.py reports the relay as OUR-SERVICE and nothing flagged.

6. After the first sale

  • Keep the merchant API key backed up and rotate it in the store, then update the relay secret. A rotation needs no product release.
  • Keep the order → key ledger (the store's portal shows it); diarise window ends so an update can be offered.
  • Run the licence and price batches after any change: pytest tests/test_licence_key_activation.py tests/test_licensing_outbound_wording.py tests/test_landing_price.py -q.

Definition of done

A stranger can click Buy Pro, pay $499, receive a licence key, activate it once, and see tancat licence status report the key and its window - then run the product with the network off. No provider is named on any page they read, and no server of ours holds anything but the merchant key.
