TanCat Pro Deployment Licence

Install and licence activation — one deployment, billed monthly, includes support and updates while your licence is active.

1. What this licence covers

  • One deployment: one installation of TanCat serving one organisation.
  • Unlimited test runs and evidence exports on that deployment.
  • Support and product updates while the licence is active.
  • Not counted per user — your whole team may use it. Do not share or resell the key.

2. Requirements

  • Python 3.14+ and uv
  • An OpenAI-compatible LLM endpoint you control (llama.cpp, Ollama, LM Studio, or similar)
  • Chromium, installed by Playwright

3. Install

git clone https://github.com/tancat-ai/tancat
cd tancat && uv sync && playwright install chromium
bash launch_ui.sh      # Streamlit UI
bash launch_cli.sh     # interactive CLI

4. Activate your licence

Your licence key arrives by email when you purchase. Give it to the deployment in any one of these three ways:

  • Environment variable (best for CI): AITEST_LICENSE_KEY=<your key>
  • A file you point at: AITEST_LICENSE_FILE=/path/to/license.key
  • The default key file: save the key as ~/.ai-test-gen/license.key
Check it worked. Open the UI — the sidebar shows License & Usage. A licensed deployment reports unlimited runs and exports. If the key is missing or invalid the product keeps working on the free tier; it never locks you out of the open-source core.

5. Where your data goes

Nowhere. The product runtime makes outbound calls only to your LLM endpoint and your target site. No telemetry, no update check, no vendor call. Verified by an audit that runs in CI: docs/security/egress-audit.md.
