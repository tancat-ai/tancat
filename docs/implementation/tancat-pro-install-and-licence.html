2. Requirements

  • Python 3.14+ and uv
  • An OpenAI-compatible LLM endpoint you control (llama.cpp, Ollama, LM Studio, or similar)
  • Chromium, installed by Playwright

3. Install

git clone https://github.com/tancat-ai/tancat
cd tancat && uv sync && playwright install chromium
bash launch_ui.sh      # Streamlit UI
bash launch_cli.sh     # interactive CLI

4. Activate your licence key

Your licence is a key issued with your order. Enter it once on the machine that will run TanCat: it is activated against your purchase, and it is stored here and read from here from then on.

  • Activate: tancat licence activate XXXX-XXXX-XXXX-XXXX-XXXX, or the same field in the sidebar’s License & Usage panel.
  • Where it is stored: tancat licence status prints the path and what is stored. For CI, keep that file and point at it: AITEST_LICENCE_FILE=/etc/tancat/licence.json
  • Confirm it: tancat licence status reports the instance, the activation date, the tier and when the update window ends.
When it is checked again. Only when you install a new version — never in between. Between those moments it works offline: the licence stored on this machine is read, not re-checked. If the store reports the key as revoked or expired, the upgrade is refused and the version you are running keeps working. If the check cannot be made, the upgrade goes ahead on the licence stored on your machine. A key the store disables is noticed at your next update, not before.
Check it worked. Open the UI — the sidebar shows License & Usage. An activated deployment reports unlimited runs and exports. A missing key, or one the service cannot confirm, leaves the product working on the free tier; it never locks you out of the free core, and it never asks you to pay again.

5. Where your data goes

Your data stays on your machines when you point TanCat at a local or self-hosted LLM. The product runtime makes outbound calls only to your configured LLM endpoint, your target site, our licence service when you activate a key and again when you install an update (nothing in between), and at most one version check a day to pypi.org if you leave the update check on — no telemetry. The version check sends nothing about you and settings turns it off. Cloud OpenAI and OpenRouter are supported if you choose them. Verified by an audit that runs in CI: docs/security/egress-audit.md.

6. Updates

Updates are installable Python packages, released on the releases page (github.com/tancat-ai/tancat/releases). You choose when to upgrade, the way you upgrade any Python tool. Installing one is the moment your licence key is checked again.
