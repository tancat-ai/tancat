# Egress Audit — "no data leaves your deployment"

**Claim under audit:** the product's **runtime** makes outbound HTTP calls only to
(i) the **customer's own LLM endpoint** (BYO-LLM, decision D1), (ii) the
**customer's own target site** being scraped (itself SSRF-guarded), (iii) **our
licence relay** - once when a key is activated and once when a new version is
installed, never in between (section 3, OUR-SERVICE), and (iv) **one PyPI version
check a day** if the update check is left on, which can be switched off and carries
nothing about the customer (`src/version_check.py`). No telemetry and no
third-party beacons.

The table in section 3 lists every call site the gate can see, and that **includes**
the version check (`src/version_check.py`): it is a hand-built `urllib` request, which
the gate matches like any other primitive. The relay rows are the only call sites
marked OUR-SERVICE.

**Caveat - model weights (see section 6).** Two optional components fetch model
weights from Hugging Face on first use: the RAG embedder, and the optional GPU
OCR backend (`OCR_BACKEND=power`). They are library-level downloads, not `src/`
call sites, so the scan in section 3 does not see them. Both can be pre-seeded;
the default OCR path (RapidOCR/PP-OCRv6 on the PyTorch engine) is offline - its
models are vendored in `src/data/ocr/` and pinned by SHA256, so it never
downloads anything.

**Verified:** 2026-11-26 · **Gate:** `python scripts/audit_egress.py` — wired into
`scripts/smoke.py` (Gate 0) and CI; **fails** if an unrecognised outbound call
site is added to the product runtime.

## 2. What counts as outbound HTTP

Scanned primitives: `httpx.{get,post,put,patch,delete,head,stream,Client,AsyncClient}`,
`requests.{…}`, `urllib.request.{urlopen,Request,build_opener}`, `urllib3`,
`aiohttp`. Excluded as **not** traffic: `urllib.parse` (pure URL manipulation),
type/exception names (`httpx.ConnectError`), identifiers ending in `requests`
(`pass3_requests`), and Playwright navigation (that is the *target* traffic,
guarded separately by `src/url_guard.py`).

Classification: a call site is **USER-CONFIGURED** when its statement references a
user-configurable or target-derived address (any `*_url` identifier, `endpoint`,
`base_url`, `candidate`, `probe_url`, env reads, `localhost` literals);
**OUR-SERVICE** when it is the one named file/address pair in `OUR_SERVICE_SITES` (the
licence relay); anything else is **FLAGGED** and fails the gate.

## 4. The other half: inbound (what the scraper may *reach*)

The no-egress claim has two halves. Outbound (this doc) is verified by the gate.
**Inbound reachability** of the scraper — the SSRF guard — is the companion
feature: `src/url_guard.py` refuses scraping of link-local/metadata addresses
(including `169.254.169.254`), private networks (opt-in), and non-http(s)
schemes at every navigation entry point, plus a request-level handler for
redirects and sub-resources. See `FEATURE_SPEC_phase6_saas.md` §5.1 and
`tests/test_url_guard.py`.

## 5. Running the gate

```bash
python scripts/audit_egress.py          # human table + verdict; exit 0/1
python scripts/audit_egress.py --json   # machine-readable manifest
python scripts/smoke.py                 # Gate 0 includes the egress audit
```

**Policy:** any new outbound-HTTP call site in the product runtime must either
target a user-configured endpoint or be deliberately allow-listed *in this
document with a reason*. The gate fails otherwise — a "quick telemetry call"
cannot land silently.

## 6. Model downloads (library-level, not caught by the call-site scan)

The gate in section 3 scans the product's *own* outbound-HTTP call sites. Two
components fetch model weights through their libraries, so they do not appear in
that table and the gate cannot see them. They are disclosed here; both are
pre-seedable; neither runs unless its feature is used. The default CPU OCR tier
is **not** in this list - its models ship in the repo (next row).

| Component | When | Source | Notes |
|-----------|------|--------|-------|
| CPU OCR (`RapidOCRBackend`, `src/ocr_backends.py`) | default OCR tier, image-only PDF pages | **none - vendored** in `src/data/ocr/` | PP-OCRv6 det/rec + text-line cls + dictionary, Apache-2.0 (Baidu/PaddleOCR), each pinned by SHA256. `src/ocr_backends.py` passes explicit local paths to rapidocr, so no model URL is ever built. Refresh with `python scripts/maintenance/vendor_ocr_models.py`. |
| RAG embedder (`SentenceTransformerEmbedder`, `src/rag_store.py`) | first embed, when RAG is enabled | Hugging Face (`sentence-transformers` model), one time | the default RAG store ships a bundled pattern pack; warming the model cache before going offline pre-seeds it |
| Optional GPU OCR backend (`src/ocr_backends.py`) | first PDF parse, only when `OCR_BACKEND=power` is set | Hugging Face (vision-language OCR model, ~6 GB), one time | opt-in; needs CUDA/ROCm and its live path is untested. |

No other runtime downloads. For a fully offline deployment: leave `OCR_BACKEND`
at its default, and warm the RAG embedder's model cache (and, only if you use
the GPU OCR tier, its model) before the machine is air-gapped.
