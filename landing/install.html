Install and add your licence

One licence covers one deployment. You receive a licence key with your order; you activate it once on this machine, and it is checked again only when you install an update. Between those moments it works offline. This page mirrors the PDF that ships with every order.

1. Install

You need Python 3.14+, uv, Chromium, and an OpenAI-compatible LLM endpoint you control (llama.cpp, Ollama, or LM Studio).

# get the code and dependencies
git clone https://github.com/tancat-ai/tancat
cd tancat && uv sync && playwright install chromium

# start the UI (or: bash launch_cli.sh)
bash launch_ui.sh

2. Activate your licence key

Your key is in your order email. Enter it once on the machine that will run TanCat: it is activated against your purchase and stored here, and from then on the product reads it from this machine.

Activate
tancat licence activate XXXX-XXXX-XXXX-XXXX-XXXX

In the UI, the sidebar’s License & Usage panel has the same field.

Where it is stored

The key and its activation are kept on this machine. Run this to see the exact path and what is stored:

tancat licence status

For CI and containerised runs, keep that file and point at it: AITEST_LICENCE_FILE=/etc/tancat/licence.json.

3. Check it worked

Run tancat licence status. An activated key reports the instance, the date it was activated and when the update window ends; the sidebar’s License & Usage panel shows the tier.

An activated deployment reports
Source:       activated licence key (...\licence.json)
Licence key:  00000-...-00000
Instance:     acme-laptop (lki_...)
Activated:    2026-11-26
Tier:         pro
Updates to:   2027-11-26

The panel then shows Runs: <n> (unlimited) and Evidence exports: <n> (unlimited).

If the key is refused, or the service is unreachable

Activation tells you why in one sentence - the key is not recognised, it is already on its maximum number of machines, or the service could not be reached. Nothing on this machine changes, and the product keeps working on the Free tier until you connect and retry. A working licence is never taken away by a refused activation.

When it is checked again

Only when you install a new version. If the store reports the key as revoked or expired, the upgrade is refused and the version you are running keeps working. If the check cannot be made, the upgrade goes ahead on the licence stored here. Between updates, nothing is checked - so a key the store disables is noticed at your next update, not before.

In CI

Activate the key once on a machine, store the licence file it writes as a secret (for example a GitHub Actions secret), write it to a path on the runner, and point the product at it with AITEST_LICENCE_FILE. The job then needs no network for licensing: it reads the stored licence, and the next check happens only when you install a new version.

Where your data goes

Your data stays on your machines when you point TanCat at a local or self-hosted LLM. The runtime makes outbound calls only to your configured LLM endpoint, your target site, our licence service when you activate a key and again when you install an update (nothing in between), and at most one version check a day to pypi.org if you leave the update check on (it sends nothing about you, and settings turns it off) — no telemetry. Cloud OpenAI and OpenRouter are supported if you choose them. Verified by an audit that runs in CI: docs/security/egress-audit.md.

Updates

This licence is perpetual for the version you receive. It does not expire.

It includes all updates released within 12 months of purchase.

Updates released after that are not included and can be bought separately if you want them.

Nothing renews automatically. You will not be charged again unless you choose to buy.

Security fixes and bug fixes for the version you hold are provided at no charge.

Updates are released as installable Python packages on the releases page, and you upgrade the way you upgrade any Python tool. You choose when to install one. The product makes exactly one automatic call - a version check at most once a day if you leave it on. Licensing is offline: your licence file is verified locally. It has no automatic upgrade - you choose when to install one.
